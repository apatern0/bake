# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful, assume good faith, and keep discussions about the work.

Report unacceptable behaviour to the maintainer through a private GitHub message or the email
address on the maintainer's GitHub profile. Reports are handled confidentially.
